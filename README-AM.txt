NARDI ROYALE — VERCEL ՏԵՂԱԴՐՈՒՄ

1. Բացեք vercel.com և ընտրեք Add New → Project։
2. Վերբեռնեք այս թղթապանակի ամբողջ պարունակությունը՝ ոչ թե միայն index.html-ը։
3. Framework Preset-ը թողեք Other, իսկ Build Command-ը և Output Directory-ն՝ դատարկ։
4. Սեղմեք Deploy։
